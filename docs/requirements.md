# 画像加工・編集アプリケーション 要件定義書

- 版: 1.0
- 対象: 初版 (v0.1.0)

要件には ID を振る。Issue・PR・コミットではこの ID で参照する（例: `FR-FLT-02`）。

---

## 1. 概要

ユーザーが画像ファイルをドラッグ＆ドロップし、リサイズ・フィルター加工・トリミングを設定して、結果を画像ファイルとして保存できるデスクトップアプリケーション。

## 2. 実行環境・技術スタック

| 項目 | 内容 |
|---|---|
| 対象 OS | macOS 13 以降 / Apple Silicon (arm64) |
| 言語 | Python 3.11 以上 |
| GUI | PyQt6 |
| 画像処理 | Pillow（必要に応じて numpy） |
| テスト | pytest, pytest-qt |
| Lint/Format | ruff |
| 構成管理 | GitHub（Issue / Pull Request / GitHub Actions） |
| 開発支援 | Claude Code |

> **ライセンス上の注意:** PyQt6 は GPL v3 または商用ライセンス。アプリを GPL 以外で配布する予定がある場合は、API がほぼ同じ PySide6 (LGPL) への切り替えを検討する。個人利用・GPL 公開なら PyQt6 のままでよい。

## 3. 対応ファイル形式

| ID | 形式 | 拡張子 | 読込 | 保存 | 備考 |
|---|---|---|---|---|---|
| FR-IO-01 | PNG | .png | ○ | ○ | 透過を保持 |
| FR-IO-02 | JPEG | .jpg .jpeg | ○ | ○ | 保存品質は 1〜100 で指定（既定 90、FR-UI-56）。透過は白背景に合成 |
| FR-IO-03 | GIF | .gif | ○ | ○ | 先頭フレームのみ（アニメは通知して先頭のみ扱う） |
| FR-IO-04 | TIFF | .tif .tiff | ○ | ○ | 複数ページは先頭のみ |
| FR-IO-05 | BMP | .bmp | ○ | ○ | 透過なし |

- FR-IO-06: 拡張子は大文字・小文字を区別しない。
- FR-IO-07: 読み込み時に EXIF の Orientation に従って回転を補正する。
- FR-IO-08: CMYK・16bit・パレット画像は内部で RGB / RGBA に変換して扱う。
- FR-IO-09: 保存形式は保存ダイアログで指定した拡張子から決める。デフォルトは元ファイルと同じ形式、ファイル名は `<元の名前>_edited.<拡張子>`。
- FR-IO-11: 元の画像には上書き保存しない。保存ダイアログで元の画像と同じファイル（macOS のため大文字・小文字の違いも同じとみなす）を選んだ場合は「元の画像と同じファイルには保存できません」と通知してダイアログを開き直す。拡張子が違えば別のファイルとして保存できる。保存ダイアログの初期のファイル名 `<元の名前>_edited.<拡張子>` がすでにあれば、`_edited_2`、`_edited_3` … と既存のファイルと重ならない名前を提案する。
- FR-IO-12: 元画像の EXIF（撮影日時・カメラなど）を、設定（FR-UI-56）に応じて保存先に残す。書き込むのは JPEG・PNG・TIFF（GIF・BMP には書かない）。
  - 向き (Orientation) は読み込み時に補正済み（FR-IO-07）なので 1（そのまま）にし、他のアプリで開いても回転しないようにする。
  - Exif IFD の画像の幅・高さ（PixelXDimension / PixelYDimension）は保存する画像の大きさに合わせる。
  - 位置情報 (GPS) は、設定で「位置情報も残す」を選んだときだけ残す（既定は外す）。
  - EXIF が壊れていて読めない画像も読み込めるようにし、その場合は EXIF なしとして扱う。
- FR-IO-10: 非対応ファイル・破損ファイルがドロップされた場合はエラーダイアログを表示し、アプリは落ちない。

## 4. 画面構成

1 つのメインウィンドウで構成する（初期サイズ 1200×800、最小 900×600）。

```
┌───────────────────────────────┬──────────────────┐
│                               │ ■ サイズ変更      │
│                               │   幅 [    ] px   │
│     D&D エリア / プレビュー     │   高 [    ] px   │
│                               │   ☑ 縦横比を保持  │
│  「ここに画像をドロップ」        │ ■ 加工           │
│                               │ [なし   ▼][ﾌﾟﾘｾｯﾄ▾]│
│                               │   ﾌﾚｰﾑ [なし ▼]  │
│                               │   形 [矩形  ▼]   │
│                               │   角丸 [──●──]   │
│                               │   露出 [──●──]   │
│                               │   明るさ [──●──] │
│                               │   ｺﾝﾄﾗｽﾄ [──●──] │
│                               │   温度 [──●──]   │
│                               │   彩度 [──●──]   │
│                               │   減光 [──●──]   │
│                               │   劣化 [──●──]   │
│                               │   [加工をリセット] │
│                               │ ■ 回転・反転      │
│                               │ [左][右][⇆][⇅]  │
│                               │ ■ トリミング      │
│                               │   比 [自由▼]☐縦 │
│                               │   X [ ] Y [ ]    │
│                               │   幅[ ] 高[ ]    │
│                               │   [クリア][実行] │
│                               │ ▶保存の設定 JPEG 90…│
│                               │[加工前][保存][ﾘｾｯﾄ]│
├───────────────────────────────┴──────────────────┤
│ ステータスバー: ファイル名 / 原寸 / 出力予定サイズ      │
└──────────────────────────────────────────────────┘
```

### 4.1 D&D エリア（左）

- FR-UI-01: 画像未読込時は「ここに画像をドロップしてください」と点線枠を表示する。
- FR-UI-02: ドラッグ中、対応形式ならハイライト表示し、非対応なら受け付けない。
- FR-UI-03: 複数ファイルをドロップした場合は先頭の 1 枚のみ読み込み、ステータスバーで通知する。
- FR-UI-04: 読み込み後はプレビューをエリアに収まるよう縦横比を保って表示する。ウィンドウリサイズに追従する。
  - 透過部分は市松模様（白と薄い灰色、1 マス 8px）の上に重ねて表示し、半透明部分は模様が透けて見えるようにする。模様は画像の範囲にだけ描き、不透明な画像では描かない。
- FR-UI-05: メニュー「ファイル > 開く… (⌘O)」からも読み込める。

### 4.2 設定パネル（右）

**サイズ変更**
- FR-UI-10: 幅・高さ (px) の入力欄。範囲 1〜20000。空欄のときはリサイズしない。
- FR-UI-11: 「縦横比を保持」チェック（初期 ON）。ON のとき片方を変更するともう片方を自動計算する。
- FR-UI-12: 初期値はトリミング後のサイズ（トリミングなしなら原寸）。フレームを選んでいるときは、写真部分の比率に切り抜いた後のサイズ（FR-FRM-02）。フレームなしで形が円のときは、正方形に切り抜いた後のサイズ（FR-SHP-02）。

**加工種類（テイスト）**
- FR-UI-20: プルダウンで選択（色だけを変え、大きさは変えない。フレームは FR-UI-50 で別に選ぶ）: なし / セピア / モノトーン / ハイトーン / ポラロイド風 / ポジフィルム風 / レトロカメラ風 / ハイキー / ローキー / ドラマチック / モダン / ナチュラル / シネマティック / ノワール / ブリーチバイパス / パステル / クロスプロセス / 青写真 / 夏らしい / 秋らしい / ソフトフォーカス / HDR 風 / 赤外線風。
- FR-UI-21: 「周辺減光」スライダー（0〜100、既定 0 = なし）で周辺減光の強さを指定する。現在値を横に表示する。画像の読み込み時に 0 に戻す。
- FR-UI-22: 「経年劣化」スライダー（0〜100、既定 0 = なし）で経年劣化の強さを指定する。現在値を横に表示する。画像の読み込み時に 0 に戻す。
- FR-UI-23: 「色温度」スライダー（2000〜10000K、100K 刻み、既定 6500K = 変化なし）で色温度を指定する。現在値を「6500 K」のように横に表示する。画像の読み込み時に 6500K に戻す。
- FR-UI-24: 「彩度」スライダー（-100〜+100、既定 0 = 変化なし）で彩度を指定する。現在値を「+30」「-50」のように符号付きで横に表示する。画像の読み込み時に 0 に戻す。
- FR-UI-25: 「明るさ」スライダー（-100〜+100、既定 0 = 変化なし）で明るさを指定する。現在値を「+30」「-50」のように符号付きで横に表示する。画像の読み込み時に 0 に戻す。
- FR-UI-27: 「コントラスト」スライダー（-100〜+100、既定 0 = 変化なし）でコントラストを指定する。現在値を「+30」「-50」のように符号付きで横に表示する。画像の読み込み時に 0 に戻す。
- FR-UI-28: 「露出」スライダー（-5.0〜+5.0 EV、0.1 刻み、既定 0.0 = 変化なし）で露出を指定する。現在値を「+1.3 EV」のように横に表示する。画像の読み込み時に 0.0 EV に戻す。
- FR-UI-29: 設定パネルは、ウィンドウが小さく縦に収まらないときは縦にスクロールできるようにする（横はスクロールさせず、スクロールバーが出てもラベルが欠けない幅を確保する）。
- FR-UI-50: 「フレーム」プルダウン（なし / ポラロイド / チェキ、既定 = なし）でフレームを選ぶ。テイスト（FR-UI-20）とは独立していて、どのテイストとも組み合わせられる。画像の読み込み時に「なし」に戻す。
- FR-UI-51: 「形」プルダウン（矩形 / 角丸 / 円、既定 = 矩形）で写真の形を選ぶ。テイスト・フレームとは独立していて、自由に組み合わせられる。画像の読み込み時に「矩形」に戻す。
- FR-UI-52: 「角丸」スライダー（0〜50%、既定 10%）で角の丸み（短辺に対する半径の割合）を指定する。現在値を「10%」のように横に表示する。形が「角丸」のときだけ操作できる。画像の読み込み時に 10% に戻す。
- FR-UI-53: 「加工」のスライダー（角丸・露出・明るさ・コントラスト・色温度・彩度・周辺減光・経年劣化）は、ダブルクリックでその項目を既定値（角丸 10%、露出 0.0 EV、色温度 6500K、ほかは 0）に戻す。操作できないスライダー（形が角丸以外のときの角丸など）は戻さない。
- FR-UI-54: 「加工をリセット」ボタンで、テイスト（FR-UI-20）と色のスライダー（露出〜経年劣化）・ディテール（FR-UI-60）をまとめて既定値に戻す。画像・サイズ変更・トリミング・フレーム・形・角丸はそのまま残す（フレーム・形・角丸は切り抜きや出力サイズに関わるため）。確認ダイアログは出さない。画像ごと未読込に戻す「リセット」（FR-UI-42）とは別。
- FR-UI-56: 保存ボタンの上に「保存の設定」を置く。見出しのクリックで開閉でき、既定は閉じる。閉じているときは「JPEG 90 ／ EXIF あり（位置情報なし）」のように 1 行で要約を表示する。
  - 「JPEG 品質」スライダー（1〜100、既定 90）。ダブルクリックで 90 に戻る。
  - 「撮影情報 (EXIF) を残す」（既定 ON）と「位置情報 (GPS) も残す」（既定 OFF）。位置情報は EXIF を残すときだけ選べる（FR-IO-12）。
  - これらは保存の好みなので、画像の読み込み・リセット・「加工をリセット」では戻さず、アンドゥ／リドゥの対象にもしない。開閉の状態も含めてアプリの環境設定（`QSettings`）に残し、次に起動したときも前回の値を使う。
  - 高さ 900px のウィンドウでも閉じた状態ならスクロールせずに収まるよう、設定パネルのグループ間の間隔を少し詰める。
- FR-UI-58: 形（FR-UI-51）が角丸・円のときは、通常の表示（元の画角全体＋トリミング範囲のマスク）でも、形の外側を範囲外と同じように半透明で暗くし、形の輪郭を線で描く。角丸の値を変えるとすぐに形が変わるので、半径を見ながら調整できる。
  - 形をかける範囲は実際に切り抜く範囲（トリミング範囲。フレーム・円のときはその比に合わせた範囲。範囲がなければ画像全体、フレームなしの円は中央の正方形）で、保存結果と同じ形・位置にする（角丸は短辺 × 角丸の値 %、円は短辺を直径とする中央の正円）。
  - 範囲のドラッグ（新規選択・移動・四隅のハンドル）は今までどおりできる。
- FR-UI-59: **プリセット**: テイストのプルダウンの右の「プリセット ▾」ボタンで、名前付きの加工の組み合わせを保存・呼び出し・削除する。
  - プリセットが持つのは、テイスト・色の調整（露出〜経年劣化）・ディテール（シャープ・ぼかし・ノイズ除去）・フレーム・形・角丸。サイズ変更・トリミング範囲・回転・反転・比の選択は画像ごとの設定なので含めない。
  - メニュー: 保存したプリセットの一覧（選ぶと今の画像に当てはめる）／「今の加工をプリセットとして保存…」／「削除」（一覧のサブメニュー）。プリセットがなければ「（保存したプリセットはありません）」と出し、「削除」は選べない。
  - 当てはめると設定パネルとプレビューに反映する。サイズ変更・範囲・向きはそのままで、フレーム・円の比が変わるときは、フレームや形を手で選んだときと同じく範囲をその比に直す。当てはめは 1 回の操作として元に戻せる（FR-UI-43）。
  - 保存するときは名前を入力する（初期値は「プリセット 1」「プリセット 2」…の空いている名前。前後の空白は除き、最大 50 文字）。同じ名前があれば上書きを確認する。削除するときも確認する。
  - 保存先は `~/Library/Application Support/ImageEditor/presets.json`（JSON、UTF-8）。フォルダがなければ作り、書き込みは一時ファイルに書いてから置き換える（途中で失敗しても元のファイルを壊さない）。ファイルが壊れていて読めなければ、起動時にダイアログで知らせてプリセットなしで使えるようにする。一覧の中の壊れた項目（知らないテイストなど）は読み飛ばす。
- FR-UI-60: **ディテール**: 「加工」グループの「加工をリセット」と同じ行に「▶ ディテール」を置き、クリックで開閉する（既定は閉じる。開閉の状態はアプリの環境設定に残す）。開くと「シャープ」「ぼかし」「ノイズ除去」のスライダー（どれも 0〜100、既定 0、現在値を横に表示、ダブルクリックで 0 に戻る）が出る。見出しの横には「シャープ 20・ノイズ除去 10」のように 0 でない値の要約（どれも 0 なら「なし」）を出す。見出しを「加工をリセット」と同じ行に置くので、閉じていればパネルは高くならない（FR-UI-29）。画像の読み込み時に 0 に戻す。仕様は §5.14。
- FR-UI-26: 「加工」のスライダー（露出・明るさ・コントラスト・色温度・彩度・周辺減光・経年劣化）は長さ 225px 以上でそろえ、細かく調整しやすくする。そのため設定パネルの幅は 420px 程度とし、ラベルが欠けないようにする。

**トリミング**
- FR-UI-55: 「回転・反転」の 4 つのボタン（左に回転 / 右に回転 / 左右反転 / 上下反転）で、表示中の向きに対して 90° 回転・反転する。プレビューは回転・反転した向きで表示し、向きが変わったときはデバウンスを待たずにすぐ描き直す（範囲選択の座標系とずれないように）。画像の読み込み時に元の向きに戻す。「加工をリセット」（FR-UI-54）では戻さない。
  - トリミング範囲があれば、同じ写真の部分を指すよう範囲も一緒に回転・反転する。
  - 90° 回転したときは、手で変えた幅・高さ（サイズ変更）と、比の「縦向き」（FR-UI-35）も入れ替える。
- FR-UI-30: X, Y, 幅, 高さの数値入力（回転・反転した後の原寸画像の座標系、px）。
- FR-UI-31: 画像を読み込んでいれば、プレビューの画像上をマウスでドラッグしていつでも範囲を指定でき、数値欄と相互に同期する（「トリミング実行」による切り抜き後の表示中を除く。FR-UI-34）。
  - プレビューは常に元の画角全体を表示し、選択範囲の外を半透明で暗くする。
  - 範囲外のドラッグで新規選択、範囲内のドラッグで移動、四隅のハンドルでサイズ変更。クリックのみで解除。
  - 画像の上では十字カーソル、画像の外（余白）では通常のカーソルとし、余白からは選択を始めない。
- FR-UI-32: 範囲外は画像内に収まるよう自動で補正する。幅・高さが 0 のときはトリミングしない。
- FR-UI-33: 「範囲をクリア」でトリミングを解除する。
- FR-UI-35: 「比」プルダウン（自由 / 1:1 / 4:3 / 3:2 / 16:9、既定 = 自由）と「縦向き」チェックボックスで、トリミング範囲の縦横比を固定できる。「縦向き」は 4:3 / 3:2 / 16:9 のときだけ操作でき、3:4 / 2:3 / 9:16 にする。画像の読み込み時に「自由」・横向きに戻す。比は範囲の指定を助けるだけで、保存する設定には含めない（範囲そのものが設定）。
  - 比を固定しているときは、プレビュー上の新規選択・四隅のハンドルでのサイズ変更で比を保つ（マウスの位置まで届く大きさにし、画像の端を越えるときは比を保ったまま縮める）。移動は大きさを変えない。
  - 数値入力でも比を保つ: 幅を変えると高さを、高さを変えると幅を比から計算する。X・Y を変えたときは大きさを保ち、画像からはみ出す分だけ位置を戻す。画像に収まらない大きさは、左上を固定して比を保ったまま縮める。
  - 範囲があるときに比（または縦向き）を変えると、今の範囲の中央をその比に直す。範囲がなければ何もしない。
  - 整数の px に丸めるため、比は ±1px の誤差を許す。
- FR-UI-36: フレーム（FR-UI-50）か形「円」（FR-UI-51）を選んでいるときは、比をその写真部分の比（フレームなしの円は 1:1）に固定し、プルダウンは「フレーム・円に合わせる」と表示して操作できなくする（「縦向き」も操作不可）。範囲があればその比に直すので、プレビューのマスクと実際に切り抜かれる範囲が一致する。フレームと円をやめると、プルダウンは元の選択に戻る。
  - チェキのように写真部分が縦長のフレームは、向きをドラッグの形で決める（新規選択は横に長くドラッグすれば横向き、縦に長ければ縦向き。サイズ変更は元の範囲の向きを保つ）。範囲がないときは画像の向きに合わせる（FR-FRM-03）。
- FR-UI-34: 「トリミング実行」を押すと、プレビューを切り抜いた範囲だけの表示（フィルター・周辺減光・形・フレームを反映）に切り替え、ボタンは「範囲を編集」に変わる。「範囲を編集」で元の画角全体＋マスクの表示に戻る。
  - 範囲は設定として保持し、保存時に原寸から切り抜く（元画像は変えない）。表示の切り替えは保存結果に影響しない。
  - フレームを選んでいるときは、写真部分の比率への切り抜き（FR-FRM-02）とフレームも反映した完成形を表示する。
  - 形（矩形以外）を選んでいるときは、形で切り抜いた完成形を表示する（形の外側はフレームがあればフレームの白、なければ透明で市松模様）。
  - トリミング範囲・フレーム・形（矩形以外）のどれもないときはボタンを押せない。範囲のクリア・フレームを「なし」や形を「矩形」に戻したとき（どれもなくなったとき）・画像の読み込み・リセットで全体表示に戻る。
  - 切り抜き後の表示中は、プレビュー上のドラッグによる範囲選択を行わない（数値欄での変更は表示に反映する）。

### 4.3 アクション

- FR-UI-40: **プレビューの自動更新**: 露出・明るさ・コントラスト・色温度・彩度・フィルター・フレーム・形・角丸・周辺減光・経年劣化・切り抜き表示など、見た目に影響する設定を変えると 300ms のデバウンス後にプレビューを自動で更新する（更新ボタン・メニューは置かない）。プレビューは長辺 1600px の縮小版に露出・明るさ・コントラスト・色温度・彩度・フィルターの色・周辺減光・経年劣化を適用したもので、通常は元の画角全体を表示してトリミング範囲をマスクで示す（周辺減光はトリミング範囲の中心を基準にかける。フレーム・円を選んでいるときはその比率に切り抜いた範囲が基準）。リサイズ後の大きさは表示せず、フレームは「トリミング実行」による切り抜き表示の間だけ表示する。形（角丸・円）は、通常の表示ではマスクと輪郭で示し（FR-UI-58）、切り抜き表示では形で切り抜いた完成形を表示する（最終的な出力サイズはステータスバーに表示する）。
- FR-UI-41: **保存**（⌘S）: 保存ダイアログを開き、原寸で処理して書き出す。処理中はボタンを無効化する。
- FR-UI-42: **リセット**: 画像と設定を初期状態（未読込）に戻す。未保存の変更があれば確認ダイアログを出す。
- FR-UI-43: **元に戻す／やり直す**: メニュー「編集 > 元に戻す (⌘Z)」「編集 > やり直す (⇧⌘Z)」で、設定の変更を 1 つずつ戻す・やり直す。対象は設定パネルのすべての設定（サイズ変更・回転・反転・加工・フレーム・形・トリミング範囲）と、比の選択・「縦向き」。「トリミング実行」による表示の切り替えは対象外。
  - 元画像は不変で表示・保存は常に設定から処理し直すので、設定パネルの状態のスナップショットを履歴に積んで実現する。戻すときは、比の固定で範囲を直したりせず、取ったときの値をそのまま戻す。
  - 続けて変えた分は 1 回の操作にまとめる: 変更が 0.5 秒落ち着いてから履歴に積み、スライダーや範囲をドラッグしている間は積まない（1 回のドラッグは 1 回の ⌘Z でドラッグ前に戻る）。まだ履歴に積んでいない変更も ⌘Z ですぐ戻せる。
  - 新しく変更すると、やり直せる先は消える。履歴は最大 100 件で、古いものから消す。
  - 画像の読み込み・リセットで履歴を消す。保存中は操作できない。
- FR-UI-46: **ヒストグラム**: プレビューの右下に、R・G・B（半透明で重ねる）と輝度（灰色）のヒストグラムを重ねて表示する。メニュー「表示 > ヒストグラム」(⇧⌘H) で表示・非表示を切り替え（既定は表示）、状態はアプリの環境設定に残す。画像がないときは出さない。
  - 数えるのは、実際に切り抜く範囲（なければ全体）の、形・フレームを付ける前の写真（保存される写真の色の分布）。全体表示のマスクの外側・フレームの白・形の外側・透明な画素は数えない。加工前の表示中（FR-UI-44）は加工前の分布を出す。
  - プレビューを描き直すたびに、同じ処理の途中の画像から `Image.histogram()` で求める（プレビューを 2 回描かない。長辺 1600px で数 ms）。
  - 高さは、全チャンネルの両端（0・255）を除いた最大の画素数を上端に合わせる（白飛び・黒つぶれで両端だけ多くても、ほかがつぶれないように。両端は上端で切る）。
  - マウス操作は下に通す（範囲のドラッグを妨げない）。
- FR-UI-45: **まとめて処理**: メニュー「ファイル > まとめて処理…」で、複数の画像に同じ加工をかけて指定したフォルダに保存する。
  - ダイアログで、処理する画像（「ファイルを追加…」「フォルダを追加…」。フォルダは直下の対応形式の画像だけを名前順に。隠しファイルは除く。同じファイルは二重に加えない）、かける加工、リサイズ、保存先のフォルダを選ぶ。開いている画像があれば最初から一覧に入れておく。画像と保存先がそろうまで「開始」は押せない。
  - かける加工は「今の加工」か、保存したプリセット（FR-UI-59）のどれか。テイスト・色の調整・フレーム・形・角丸をかける。トリミング範囲と回転・反転は画像ごとに違うのでかけない（フレーム・円のときは、各画像の中央をその比で切り抜く）。
  - リサイズは「リサイズしない」か「長辺を N px にする」（1〜20000）。縦長・横長が混ざっていても長辺がそろう。長辺はフレーム・円の比に切り抜いた後の写真で決め、フレームはその外側に付く。N の初期値は今の画像の幅・高さの長いほう（画像を開いていなければ 2048）で、今の画像をリサイズしていればリサイズする設定で開く。
  - 保存は元と同じ名前・形式で、指定したフォルダに書く。同じ名前のファイルがある、または元のファイルそのものになるときは `_edited`、`_edited_2` … を付けて上書きしない。JPEG 品質・EXIF・位置情報は「保存の設定」（FR-UI-56）に従う。元の画像は変えない。
  - 処理はワーカースレッドで 1 枚ずつ行い、進み具合（何枚目か・ファイル名）と「中止」を出す。中止すると、処理中の 1 枚を終えたところで止まる。読み込めない・保存できない画像があっても残りは続け、終わったら保存した枚数と、処理できなかった画像（最大 10 件と理由）を知らせる。実行中は保存・開く・まとめて処理を始められない。
- FR-UI-44: **加工前との比較**: `\` キー（JIS 配列では同じ位置の `¥` キーも可）か、設定パネル下の「加工前」ボタンを押している間だけ、加工前の画像をプレビューに表示し、離すと加工後に戻す。表示中はプレビューの左上に「加工前」と表示する。
  - 加工前は、向き（回転・反転）と表示範囲（全体＋マスク／切り抜き表示）はそのままで、色の調整（露出〜彩度）・テイスト・周辺減光・経年劣化・形・フレームを外したもの。切り抜き表示では、フレーム・円の比に合わせた範囲をそのまま表示する。設定は変えない。
  - キーはどの入力欄にフォーカスがあっても効き、文字として入力されない。押しっぱなしの自動リピートは無視する。ウィンドウが非アクティブになったら加工後の表示に戻す（キーを離したことが届かないため）。
  - 画像の読み込み・リセットで加工後の表示に戻す。

## 5. 画像処理仕様

### 5.1 処理順序（固定）

```
原画像 → EXIF 回転補正 → 回転・反転 → トリミング → (フレームありのみ) 写真部分の比率に切り抜き / (フレームなしで円のみ) 正方形に切り抜き → リサイズ → 露出 → 明るさ → コントラスト → 色温度 → 彩度 → ディテール（ノイズ除去 → ぼかし → シャープ） → フィルター → 周辺減光 → 経年劣化 → (角丸・円のみ) 形で切り抜き → (フレームありのみ) フレーム付与
```

- FR-PRC-01: 処理は常に原画像から再計算する（フィルターを重ね掛けしない）。
- FR-PRC-05: 回転・反転は向き（左右反転の有無 + 時計回りの回転角 0 / 90 / 180 / 270）として持ち、処理の最初（EXIF 回転補正の後）に `Image.transpose` で適用する。回転・反転の組み合わせはこの 8 通りのどれかにまとめる。トリミング範囲は回転・反転した後の原寸画像の座標系で持つ。
- FR-PRC-02: フレームはリサイズ後に付与するため、出力サイズは指定サイズより大きくなる。ステータスバーに最終出力サイズを表示する。
- FR-PRC-03: 透過 (アルファ) はトリミング・リサイズ・露出・明るさ・コントラスト・色温度・彩度・フィルター・周辺減光・経年劣化の後も保持する（露出・明るさ・コントラスト・色温度・彩度・フィルター・周辺減光・経年劣化は RGB に適用し、アルファは元のまま戻す）。形（FR-SHP-01）はフレームなしのとき外側を透明にするので、出力は RGBA になる。
- FR-PRC-04: フレームは周辺減光・経年劣化の後に付与し、フレームには露出〜経年劣化の補正・加工をかけない（フレームは白のまま）。

### 5.2 トリミング
- FR-TRM-01: `Image.crop((x, y, x + w, y + h))` で切り抜く。

### 5.3 リサイズ
- FR-RSZ-01: `Image.resize(size, Image.Resampling.LANCZOS)` を使う。
- FR-RSZ-02: 縦横比保持時の端数は四捨五入、最小 1px。

### 5.5 周辺減光

- FR-VIG-01: 出力画像（トリミング・リサイズ後）の中心を基準に、縦横比に合わせた楕円状に周辺を暗くする。強さは 0〜100（0 は変化なし）。
- FR-VIG-02: 中心から上下左右の端までの距離を 1 としたとき、0.35 より内側は変えず、そこから四隅（√2）に向かって滑らかに暗くする。強さ 100 のとき四隅の明るさを 8 割落とす。
- FR-VIG-03: 放射状グラデーションと LUT、`ImageChops.multiply` で処理し、画素ごとの Python ループは使わない。係数は `core/effects.py` 内で定数として定義する。

### 5.6 経年劣化

- FR-AGE-01: 強さ 0〜100 で、時間が経ったような風合いを付ける（0 は変化なし）。以下の要素を強さに比例して効かせる（値は強さ 100 のとき）。
  - 退色: `ImageEnhance.Color` で彩度を 4 割まで落とす
  - フェード: 黒を 45 まで浮かせ、白を 230 まで抑える
  - 黄ばみ・青の抜け: R×1.08、B×0.72 の色かぶり
  - 粒子: 明るさ ±14 程度のモノクロ粒子。乱数シードを固定し、同じ入力なら毎回同じ結果にする（縮小プレビューでは原寸より粗く見える）
- FR-AGE-02: フェードと色かぶりは 1 回の LUT (`Image.point`) で処理し、画素ごとの Python ループは使わない。係数は `core/effects.py` 内で定数として定義する。
- FR-AGE-03: 画素ごとの色の変化なので、プレビューではトリミング範囲に関係なく表示範囲全体にかける。

### 5.7 色温度

- FR-TMP-01: 2000〜10000K で指定し、その色温度の光で照らしたような色にする。6500K（昼光）は変化なし、低いほど暖色（電球色）、高いほど青み（曇り空・日陰）。
- FR-TMP-02: 黒体放射の色（Tanner Helland の近似式）の 6500K に対する比から R / G / B の倍率を求め、差を 0.5 倍に弱めたうえで輝度が 1 になるよう正規化する（明るさをほぼ保つ）。LUT (`Image.point`) で適用する。
- FR-TMP-03: 写真アプリのホワイトバランスと同じく、フィルターの前にかける（モノトーン・セピアでは色温度の色味は残らない）。

### 5.8 彩度

- FR-SAT-01: -100〜+100 で指定する。`ImageEnhance.Color` に 1 + 値/100 を渡し、-100 で白黒、0 で変化なし、+100 で鮮やかさ 2 倍にする。
- FR-SAT-02: 色温度と同じく写真そのものの補正として、色温度の後・フィルターの前にかける（モノトーン・セピアでは彩度の変化は残らない）。

### 5.9 明るさ

- FR-BRT-01: -100〜+100 で指定する。中間の明るさをトーンカーブ（ガンマ = 2^(-値/50)、+100 で 0.25、-100 で 4）で持ち上げ・押し下げ、黒 (0) と白 (255) は変えない（白飛び・黒つぶれしにくい）。LUT (`Image.point`) で適用する。
- FR-BRT-02: 写真そのものの補正として、露出の後・コントラスト・色温度・彩度の前にかける。

### 5.10 コントラスト

- FR-CON-01: -100〜+100 で指定する。プラスは S 字のトーンカーブ（smoothstep を値/100 の割合で混ぜる）で明暗の差を強め、黒 (0) と白 (255) は変えない（白飛び・黒つぶれしにくい）。マイナスは中間の灰色 (128) に向けて差を縮め、-100 で差を半分にする（フェードした調子）。LUT (`Image.point`) で適用する。
- FR-CON-02: 写真そのものの補正として、明るさの後・色温度の前にかける。

### 5.11 露出

- FR-EXP-01: -5.0〜+5.0 EV（0.1 刻み）で指定する。色を sRGB からリニア（光の量）に直して 2^EV 倍し、sRGB に戻す（+1.0 EV で光の量 2 倍、-1.0 EV で半分）。カメラの露出補正と同じく、明るい部分は白く飛び、暗い部分は沈む（トーンカーブで調整する明るさとの違い）。LUT (`Image.point`) で適用する。
- FR-EXP-02: 基本補正の最初（リサイズの後・明るさの前）にかける。

### 5.12 フレーム

- FR-FRM-01: 写真の周囲に、インスタントカメラの台紙のような白いフレームを付ける。寸法は実物のおおよその値（縦向きのカード、mm）で、`core/frames.py` 内で定数として定義する。

  | フレーム | カード | 写真部分 | 余白 (左, 上, 右, 下) |
  |---|---|---|---|
  | ポラロイド（600 / i-Type） | 88×107 | 79×79 | 4.5, 6, 4.5, 22 |
  | チェキ（instax mini） | 54×86 | 46×62 | 4, 6.5, 4, 17.5 |

- FR-FRM-02: 写真は、トリミング範囲（なければ画像全体）の中央をフレームの写真部分の縦横比に切り抜いてから入れる（長すぎる側を両端から均等に削る）。切り抜きは原画像の座標系で計算し、処理順はトリミングの直後・リサイズの前とする。
- FR-FRM-03: 写真部分が縦長のフレーム（チェキ）に横長の写真を入れるときは、カードを横向きにする（反時計回りに 90° 回した形で、写真部分は 62:46、下の広い余白が右に来る）。正方形の写真は縦向きのカードにする。
- FR-FRM-04: 余白の太さは、リサイズ後の写真の大きさから実物の比率で計算する（縮尺 = 写真部分の mm に対する px の比。写真の縦横比が写真部分と違うときは収まる側の縮尺）。四捨五入、最小 1px。
- FR-FRM-05: フレームの色は白 (255, 255, 255) で不透明。写真の透過はそのまま残す。

### 5.13 形（角丸・円）

- FR-SHP-01: 写真を形で切り抜く。形の外側は、フレームがあればフレームの白 (FR-FRM-05) で不透明に塗り、なければ透明にする。写真自体の透過はそのまま残す。透明部分は PNG・TIFF ではそのまま保存し、JPEG・BMP では白背景に合成する（FR-IO-02 / 05）。GIF は Pillow の変換に従う（半透明の縁は透明か不透明のどちらかになる）。
  - 矩形: 切り抜かない
  - 角丸: 角の半径 = 短辺 × 角丸の値 %（0〜50）。50% で両端が半円のカプセル形になる。0% は矩形と同じ
  - 円: 写真（フレームがあれば写真部分）の中央の、短辺を直径とする正円
- FR-SHP-02: フレームなしで円を選ぶと、トリミング範囲（なければ画像全体）の中央を正方形に切り抜く（出力は正方形）。切り抜きは原画像の座標系で計算し、処理順はトリミングの直後・リサイズの前とする。フレームがあるときは写真部分の比率への切り抜き (FR-FRM-02) を優先し、円はその中に描く（例: チェキ＋円 → 縦長の写真部分の中に、短辺を直径とする円）。
- FR-SHP-03: 形で切り抜くのは周辺減光・経年劣化の後、フレームの前。形の外側には周辺減光・経年劣化をかけない。
- FR-SHP-04: 縁はアンチエイリアスをかけ、ギザギザにしない。角の部分（半径四方）だけを `ImageMath` で計算して四隅に反転して貼り、画素ごとの Python ループは使わない（大きな画像でも角の大きさ分だけの計算で済む）。

### 5.14 ディテール（シャープ・ぼかし・ノイズ除去）

- FR-DTL-01: 基本補正（露出〜彩度）の後・フィルターの前に、ノイズ除去 → ぼかし → シャープの順にかける。RGB にのみ適用し、アルファは元のまま戻す。画素ごとの Python ループは使わない。係数は `core/effects.py` 内で定数として定義する。
- FR-DTL-02: 半径は写真の短辺に比例させ、縮小プレビューと原寸の保存結果で効き方をそろえる。基準の短辺は、保存時は切り抜き・リサイズ後の写真、プレビューは実際に切り抜く範囲（なければ全体）のプレビュー上の大きさ（全体表示でも同じ）。
  - シャープ: `ImageFilter.UnsharpMask`。半径は短辺の 0.12%（下限 1px。小さい画像でも効くように）、強さは 100 で 250%、しきい値 2。プレビューでは保存時の半径（下限込み）を表示の縮尺に換算する。
  - ぼかし: `ImageFilter.GaussianBlur`。半径は 100 で短辺の 1%。
  - ノイズ除去: 短辺の 0.2% の半径でぼかした画像との差が小さい（なめらかな）部分ほどぼかした画像を混ぜ、差が 40 以上の輪郭は元のまま残す（smoothstep でなめらかに切り替える）。混ぜる割合の上限は 値/100。ノイズは縮小するだけで薄れるので、縮小プレビューでは原寸より効きが弱く見える。

## 6. 非機能要件

- NFR-01: 12MP (4000×3000) の JPEG で、読み込みからプレビュー表示まで 1 秒以内（M1 相当）。
- NFR-02: 設定変更からプレビュー更新まで 200ms 以内（縮小プレビュー使用）。
- NFR-03: 原寸処理・保存中も UI が固まらない（ワーカースレッドで処理）。
- NFR-04: 例外が発生してもアプリを終了させず、ダイアログで通知する。想定外の例外は `~/Library/Logs/ImageEditor/image_editor.log` に記録する。
- NFR-05: `core/` のテストカバレッジは主要関数を網羅する（フィルター・トリミング・リサイズ・入出力の各形式）。

## 7. スコープ外（初版では実装しない）

- アニメーション GIF の全フレーム処理
- 任意角度の回転（90° 単位の回転・反転は FR-UI-55 で対応済み）・文字入れ
- 他の Mac への配布（Developer ID 署名・Apple の公証）。.app のビルドと自分の Mac での利用は FR-APP-01 で対応済み
