## 作業内容
- `ui/crop_overlay.py`: プレビュー上でドラッグして矩形を選択、半透明マスクで範囲外を暗く表示
- 表示座標 ⇔ 原画像座標の換算（プレビューの縮小率・余白オフセットを考慮）
- 数値欄と双方向に同期
- 選択範囲の移動・四隅ハンドルでのサイズ変更はできれば対応（難しければ別 Issue に切り出す）

## 受け入れ条件
- [ ] ドラッグした範囲と保存結果の切り抜き範囲が一致する（誤差 ±1px 程度）
- [ ] 座標換算関数のユニットテスト
- [ ] 画像外へのドラッグが画像内にクランプされる
